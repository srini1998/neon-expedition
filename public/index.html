A SMALL GAME. REAL LEARNING.

Every move is an experiment.

The agents use tabular Q learning. They learn a value for each possible move from each state, rather than following a route written in advance.

01 / State

The agent’s position and whether it has the key.

02 / Action

Move up, right, down, or left.

03 / Reward

Key +5. Exit +18. Move −0.1. Collision −0.65. Plasma uses the selected penalty.

04 / Update

Q(s,a) ← Q(s,a) + α[r + γ max Q(s′,a′) − Q(s,a)]. Discount γ = 0.97.

Exploration starts at 100% and decays toward 4%. The chart uses training episodes; evaluation disables exploration to check what the agent learned.

Atlas uses the selected hazard penalty, Nova uses 70%, and Echo uses 150%. All three learn independently on the same fixed map. This is navigation learning, not general intelligence.
